Request Flow: Users interact through Angular SPA or Web Forms. All requests pass through ASP.NET Core middleware pipeline (auth, logging, exception handling), reach REST controllers, which delegate to business services, then repository layer, and finally EF Core against SQL Server.
Authentication Flow: Login requests are validated against ASP.NET Identity, returning a JWT token. Subsequent requests include the token in the Authorization header. Middleware validates the token on every request and populates the user identity with role claims for authorization.
Business Layer: Encapsulates healthcare workflow logic — appointment scheduling rules, billing calculations, insurance eligibility checks, and pharmacy inventory policies. Services are injected into controllers via DI and are fully unit-testable.
Repository Layer: Abstracts EF Core DbContext behind interfaces. Controllers and services depend on interfaces, not concrete DbContext instances. This enables unit testing with mock repositories and allows data access optimization without changing consuming code.
Database Interactions: EF Core handles CRUD with LINQ, change tracking, and eager loading. Complex reporting queries use stored procedures and views for performance. Database migrations are managed through EF Core code-first migrations.
SignalR Communication: Real-time notifications for appointment reminders, lab result delivery, and inter-department messaging use SignalR hubs. The server pushes events to connected clients, eliminating the need for polling.
