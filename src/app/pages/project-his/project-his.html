Request Flow: Users interact through Angular SPA or Web Forms. All requests pass through ASP.NET Core middleware pipeline (auth, logging, exception handling), reach REST controllers, which delegate to business services, then repository layer, and finally EF Core against SQL Server.
Authentication Flow: Login requests validated against ASP.NET Identity, returning a JWT token. Subsequent requests include the token in the Authorization header. Middleware validates on every request and populates user identity with role claims.
Business Layer: Encapsulates healthcare workflow logic — appointment scheduling rules, billing calculations, insurance eligibility checks, pharmacy inventory policies. Injected into controllers via DI, fully unit-testable.
Repository Layer: Abstracts EF Core DbContext behind interfaces. Enables unit testing with mock repositories and allows data access optimization without changing consuming code.
Database Interactions: EF Core handles CRUD with LINQ, change tracking, eager loading. Complex reporting uses stored procedures and views. Migrations via EF Core code-first.
SignalR Communication: Real-time notifications for appointment reminders, lab result delivery, inter-department messaging. Server pushes events to connected clients — eliminating polling.
